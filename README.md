# 🌾 Crop Recommendation System

A Machine Learning project that predicts the best crop based on soil nutrients and weather conditions.

## 🚀 Features
- ML model using Random Forest
- Inputs: N, P, K, temperature, humidity, pH, rainfall
- Flask-based web UI
- Recommends the best crop

## 🛠 Tech Stack
Python, Scikit-Learn, Flask, HTML, CSS

## 🧠 How to Run

### 1. Train model
python train_model.py

### 2. Run Website
python app.py

App runs on: http://127.0.0.1:5000
